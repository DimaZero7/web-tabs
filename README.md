# web-tabs

Доска с сеткой точек — как в MyScript Notes — для записи фортепианных блоков:
верхняя строка — левая рука, нижняя — правая, справа — сколько раз повторить.
Всё стоит по точкам: клетка = 5 мм, ноты по центру столбцов, стрелка — ровно в одну клетку,
у всех блоков песни общие столбцы и одна ширина.

## Запуск

Нужен Node.js 18+. Зависимостей нет.

```bash
npm start
```

Откройте http://localhost:5178

## Как пользоваться

- **Колесо** — листать доску, **Shift+колесо** — вбок, **Ctrl+колесо** или щипок на тачпаде — масштаб.
- **Тянуть по пустому месту** — двигать доску. Замочек внизу слева закрепляет вид.
- **Клик по блоку** — выделить и открыть панель. **Тянуть блок** — переставить (по точкам, целыми клетками).
- **Стрелки** — сдвинуть выделенный блок на клетку, **Delete** — удалить, **Ctrl+D** — дублировать.
- **Ctrl+Z / Ctrl+Shift+Z** — отменить / повторить.
- **Масштаб в процентах** (внизу слева): 100% — клетка 5 мм в реальном размере; клик — вписать по ширине.
- **PNG** — выделенный блок картинкой с прозрачным фоном (например, чтобы вставить в MyScript).

## Блок на пианино

Кнопка **«▶ На пианино»** в панели блока (или двойной клик по блоку) открывает блок, как в видео:
сверху сам блок (текущий шаг подсвечен), посередине падающие ноты (левая рука — синяя,
правая — зелёная), снизу клавиатура с нажатыми клавишами, подписями нот и номерами октав.
Пробел — пуск/пауза, ← → — шаг назад/вперёд, Esc — закрыть; есть скорость, повтор по кругу и звук.

Сколько звучит нота: одна нота или аккорд в `[скобке]` — один шаг; `~` — до конца блока;
`~N` — до N-го столбца; в стопке `{…}` нота держится, пока на её строке не появится следующая.
Повторы учитываются: например, левая рука ×2 играет свою строку дважды, пока правая держит аккорд.

## Запись нот

| Запись | Что значит |
|---|---|
| `Ab1` | нота: буква, `b` или `#`, октава → «Ляb₁ (Ab₁)» |
| `>` или `→` | следующий столбец (рисуется стрелка) |
| `[Ab0 Ab1]` | аккорд «взять вместе» — стопка со скобкой |
| `{Bb1 B1 Eb2}` | стопка без скобки |
| `Eb2~` | нота держится до конца строки (линия удержания) |
| `Bb1~9` | держится до 9-го столбца — перед ним вертикальная черта |
| `_` | пустой столбец |

Пример блока:

```
Левая:  [Ab0 Ab1] > Gb1 > Eb1 > Ab1 > Gb1 > Eb1
Правая: {Bb1 B1~ Eb2}
Повторы: 2 и 1
```

## Где хранятся песни

Каждая песня — файл `songs/<имя>.json`. Правки в браузере сразу сохраняются в этот файл,
а изменения файла (руками или из другой программы) через секунду появляются в браузере.

```json
{
  "title": "The Weeknd — Call Out My Name",
  "video": "https://www.youtube.com/watch?v=pRVGKr49NaQ",
  "blocks": [
    { "id": "b1", "x": 1, "y": 1, "left": "[Ab0 Ab1] > Gb1 > Eb1", "right": "{Bb1 B1~ Eb2}", "reps": [2, 1] }
  ]
}
```

`x`, `y` — левый верхний угол блока в клетках.

## Приложение для планшета (Android)

Та же доска в приложении: щипок двумя пальцами — масштаб и сдвиг, пальцем или пером — блоки.

Песни лежат в папке на Google Диске (например, «Мой диск / web-tabs»). При первом запуске
приложение просит один раз подключить эту папку (системное окно Android: Диск → Мой диск →
«Новая папка» → «Использовать эту папку»). Дальше всё само:

- список песен — все песни из папки; новые файлы появляются сами;
- кнопка ⟳ — сохранить свои правки и подтянуть свежие версии; то же автоматически —
  при возвращении в приложение и раз в 30 секунд;
- «＋ Новая песня…» создаёт файл прямо в папке.

Правки с планшета появляются на drive.google.com примерно через полминуты. Изменения,
сделанные в облаке с другого устройства, планшет видит, когда их подтянет приложение
Google Диск (обычно в течение минуты-двух; быстрее — если открыть Диск).

Сборка без Android Studio (нужны JDK 17, Android build-tools 35 и platform 35):

```bash
python android/build.py           # → android/build/web-tabs.apk
python android/build.py install   # собрать и поставить через adb
```

Ключ подписи хранится вне репозитория (`Documents\AndroidEmulator\keys\web-tabs.jks`) —
его нужно сохранить: обновления ставятся поверх только с тем же ключом.

## Устройство

- `serve.mjs` — локальный сервер: раздаёт приложение, читает и пишет `songs/*.json`.
- `src/notation.js` — разбор записи нот.
- `src/layout.js` — раскладка блока по сетке (без рисования, проверяется тестами).
- `src/draw.js` — отрисовка: точки (фон `#000`, точки `#515151`, как в MyScript) и блоки.
- `src/main.js` — доска, мышь и клавиатура, панель блока, отмена, синхронизация с файлом.

Тесты: `npm test`.
